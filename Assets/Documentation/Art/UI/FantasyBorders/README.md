# Fantasy UI Borders — Kenney

Source: https://kenney.nl/assets/fantasy-ui-borders

Version 1.0, CC0. Original license retained in License.txt.

Selected, unmodified PNG assets:
- Frame.png: PNG/Default/Border/panel-border-000.png
- Panel.png: PNG/Default/Panel/panel-000.png

Used by FantasyUI (PlayerHUD.cs) and MainMenuView. Textures use Point filtering,
Clamp wrapping, no mipmaps and no compression. Borders use 12-pixel nine-slicing
to preserve the corner ornaments as windows resize.

Applied to the main menu, inventory window and controls, inventory equipment
slots, health/focus HUD panels and ability cards. Map and minimap are unchanged.
No Crusenho assets are included.
