# Generated inventory frames

Generated with the built-in image generation tool. Final PNG assets preserve generated alpha. Weapon and consumable frames use independently configurable textures and UV regions in InventoryUIIcons.asset; UVs exclude outer transparent margins without modifying the PNGs. Decorative shapes scale as whole images, rather than 9-slice, to retain the centered ornaments. Clear these overrides to use Slot Background / Slot Border instead.

Dark midnight navy opaque empty center, fine double gold frame, stepped corners, hollow diamond decorations at top and side midpoints, shield-shaped shallow pointed bottom. Matching elegant game UI artwork. Absolutely NO exterior backdrop, no brown gradient, no glow, no checkerboard; transparent empty pixels outside frame. No text or weapon. Keep gold subdued and outline slim.
