## Files

Eight original MagicaVoxel .vox files are stored in Assets/Art/Source/Nature/MountainLabs/VoxelTreePack. Downloads were checked for the VOX file signature. SHA-256 hashes are in VoxelTreePack-SHA256.txt.

These are compact source models, not runtime meshes. The Live Tree and Fluffy Pine samples are converted with reduced voxel density and three mesh LODs; see Conversion.md. The original sources allow regeneration, but the multi-million-triangle exact conversion is discarded. No existing tree, material, biome profile or world catalog was replaced.
