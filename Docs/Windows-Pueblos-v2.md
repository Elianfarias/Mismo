# Mismo para Windows — Pueblos v2

## Ejecutar

1. Extraer el ZIP completo en una carpeta.
2. Abrir Mismo.exe.

Conservar Mismo_Data, UnityPlayer.dll y las demás carpetas y archivos junto al ejecutable. No ejecutar el juego desde dentro del ZIP.

Versión para Windows de 64 bits. Incluye los pueblos ampliados, el apoyo al terreno corregido y su distribución más espaciada, además del mapa, criaturas y ciclo de día/noche.

Los guardados de Windows son independientes de los del navegador. Al continuar una partida anterior de Windows, el juego adapta el punto de reaparición al nuevo tamaño de los pueblos cuando corresponde.

## itch.io

Subir el ZIP como descarga para Windows. Conservar por separado la build HTML si también se ofrece jugar desde el navegador.
