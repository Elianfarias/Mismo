# Portada con assets reales

Render directo de Unity con Goblin.prefab, Spider_Standard.prefab, árboles, roca y pasto del proyecto. Tipografía compuesta con Unity UI. No utiliza imágenes generadas para la portada.

- Assets/Art/UI/Branding/Mismo-Itch-Real-630x500.png: portada para itch.io.
- Assets/Art/UI/Branding/Mismo-Itch-Real-1260x1000.png: versión de mayor resolución.

Reproducible con Mismo.Gameplay.Player.Editor.ItchCoverCapture.RunBatch en una copia aislada del proyecto. La escena es una composición promocional de los modelos reales; no una captura de gameplay. No modifica las escenas del juego ni la build publicada.
